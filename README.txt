Installation
------------

Step 1)
Extract ALL files and folders from the zip package.

Step 2)
You need to have Dune 2000 game on your computer, because the editor requires 
original Dune 2000 graphics files and some other files to work, and it needs to
know location of the game.
- If you put the editor into some folder under your Dune 2000 game folder, it
  will configure itself automatically and you will be able to use it right away.
- Otherwise editor will prompt you upon start and ask you to navigate to game
  location manually.


Additional tips
---------------
- Use built-in help (Help main menu item) to see numerous helpful keyboard shortcuts and 
  special mouse actions to utilize all the advanced map editing features.
- When designing enemy AI for your missions, use built-in help (the button with "?" mark)
  to get the information about what a particular value is doing. Same with mission rules.
- When designing events for a mission, use built-in help (the button with "?" mark)
  to get the information about what a particular event or condition is doing. 
- If you have any more questions about using the editor and creating new maps and missions,
  you can post your questions on FED2k forum as well as post your creations there!
